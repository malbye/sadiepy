# SADIE documentation

**Simulation, Analysis, and Design In Ecohydraulics.**

Physics-based prediction of wave damping by vegetation, with tradespace tools for
designing and analysing flume experiments.

```{note}
SADIE (`sadiepy`) is in early development (pre-release). The API may change.
```

SADIE predicts how regular waves decay across a patch of coastal vegetation
(mangroves, salt marsh, seagrass, kelp, or user-defined) described as a vertical
stack of layers, using linear wave theory and the energy-dissipation framework of
Dalrymple et al. (1984).

## Installation

```shell
pip install sadiepy
```
